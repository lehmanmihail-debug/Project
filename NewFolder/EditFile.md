# Это простой текстовый файл

# Курсор 

`Home` - в начало строки 

`End` - в конец строки

## Навигация (Page Up / Page Down)
`Page Down` - вниз на страницу

`Page Up` - вверх на страницу

`Shift + Page Down` - вниз на страницу с выделением

`Shift + Page Up` - вверх на страницу с выделением

## Выделение текста
`Ctrl+A` - выделить всё

`Ctrl+Shift+→` - выделение по слову вправо

`Ctrl+Shift+←` - выделение по слову влево

`Shift+↑` - выделение строк вверх

`Shift+↓` - выделение строк вниз

## Многострочное редактирование
`Ctrl+Alt+↑` - добавить курсор выше

`Ctrl+Alt+↓` - добавить курсор ниже

`Shift+Alt+I` - добавить курсоры в конец каждой строки

`Shift+Alt+мышь` - вертикальное выделение блоком

`Ctrl+D` - выделить следующее совпадение

`Ctrl+Shift+L` - выделить все совпадения

## Табуляция (отступы)
`Tab` - увеличить отступ

`Shift+Tab` - уменьшить отступ

`Ctrl+Shift+I` - автоформатирование отступов
