# 🔄 Sync Repos – Скрипты синхронизации Git-репозиториев
# 📋 Описание проекта
## Проект содержит два скрипта (Bash для Linux/macOS и PowerShell для Windows), которые автоматизируют процесс синхронизации между двумя локальными копиями репозиториев.

### Что делают скрипты:

- Выполняют git pull в исходном репозитории (получают актуальные изменения с удаленного сервера)

- Копируют все содержимое (кроме папки .git) в целевой репозиторий с заменой файлов

- Опционально выполняют git push в целевом репозитории (отправляют изменения на удаленный сервер)

- Проверяют корректность путей и наличие необходимых директорий

# ⚠️ Важные замечания
- Регистрозависимость: На Windows папки Content и content считаются одинаковыми, на Linux/macOS – разными. Скрипты учитывают это поведение ОС.

- Безопасность: Никогда не используйте русские имена файлов и каталогов

- Тестирование: Рекомендуется сначала тестировать в Docker или виртуальной машине
