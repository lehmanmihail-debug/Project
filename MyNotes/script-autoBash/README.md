# 🔄 Sync Repos – Скрипт синхронизации Git-репозиториев
# 📋 Описание проекта
## Проект содержит скрипт (Bash), который автоматизирует процесс синхронизации между двумя локальными копиями репозиториев.

### Что делает скрипт:

- Выполняет git pull в исходном репозитории (получает актуальные изменения с удаленного сервера)

- Копирует все содержимое (кроме папки .git) в целевой репозиторий с заменой файлов

- Опционально выполняет git push в целевом репозитории (отправляет изменения на удаленный сервер)

- Проверяет корректность путей и наличие необходимых директорий

# ⚠️ Важные замечания
- Регистрозависимость: На Windows папки Content и content считаются одинаковыми, на Linux/macOS – разными. Скрипты учитывают это поведение ОС.

- Безопасность: **Никогда** не используйте русские имена файлов и каталогов

- Тестирование: Рекомендуется сначала тестировать в Docker или виртуальной машине
